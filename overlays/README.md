## Usage

1. Open the [Stamptivity overlay editor](https://stamptivity.app/overlay/editor).

2. Load your activity track — pick a `.gpx` file in the **Telemetry** panel
   (use **Replace file** if a track is already loaded).

3. Open the menu (the three-line button in the top bar) and choose
   **Import project**.

4. Select one of the `.json` files from this repository.

5. The overlay is applied to the current project and is ready to adjust.
